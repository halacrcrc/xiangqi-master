# 象棋大师 Xiangqi Master

基于 **Rust + Tauri 2 + React** 的现代化中国象棋对弈与训练应用。内置自研象棋引擎、复盘分析与棋力训练体系，安装包体积仅约 1.4 MB。

![技术栈](https://img.shields.io/badge/Rust-Tauri%202-orange) ![平台](https://img.shields.io/badge/platform-Windows-blue)

## 功能

### 对弈
- **自研引擎**：alpha-beta 迭代加深搜索、置换表、空着剪枝、静态搜索、历史/杀手启发，perft 走法生成验证通过（44 / 1,920 / 79,666）
- **六档 AI 难度**：入门 → 特级大师（Elo 800–2300），低难度带拟人随机波动
- **人机 / 双人对战**，执红 / 执黑 / 随机，10 分钟 / 5 分钟快棋 / 不限时
- **完整规则**：将杀、困毙、长打判和、子力不足判和、双王照面禁手、悔棋、提示、认输

### 棋力提升
- **落子即时评价**：每步标注 最佳 / 佳着 / 欠准 / 失误 / 漏着，并给出引擎推荐着法
- **整局复盘**：逐手深度评估，双方准确度、失误清单（可跳转局面）、关键瞬间
- **杀局解谜**：马后炮、双车错、重炮杀、卧槽马、钓鱼马、中线闷杀（全部经引擎验证为强制杀）
- **残局实战**：单车胜单士 / 单象、马擒单士、炮仕胜单士、双兵胜单士、单车守和士象全
- **开局库**：实时识别中炮对屏风马、飞相局、仙人指路等开局体系
- **棋力成长**：Elo 等级分实时结算、积分曲线、胜负统计、解谜进度持久化

### 界面
- SVG 棋盘 + 立体棋子滑动动画、形势评估条、楚河汉界、将军警示
- 三套主题（墨夜 / 原木 / 青玉）、WebAudio 合成音效（零外部资源）
- 中文纵线记谱（炮二平五 / 马8进7，含前中后消歧）

## 构建与开发

```bash
npm install          # 安装前端依赖
npm run tauri dev    # 开发调试
npm run tauri build  # 生成安装包 (NSIS)
```

环境要求：Node 18+、Rust 1.77+、Windows（WebView2 运行时）。

## 目录结构

```
src/                React 前端（棋盘渲染、面板、状态管理）
src-tauri/
  src/engine/       Rust 象棋引擎（board / movegen / eval / search /
                    notation / openings / puzzles / analysis）
  src/lib.rs        Tauri 命令层与对局会话管理
  gen_icon.py       应用图标生成脚本
```
